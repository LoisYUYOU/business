# 来源摘录 03｜HBX Agent 基础设施与放权路径

- 来源：PhocusWire 对 HBX Group 首席战略、转型与 AI 官 Javier Cabrerizo 的采访
- 日期：2026-08-12
- 链接：https://www.phocuswire.com/interview/technology/ai-transformation-travel-series-hbx-group-javier-cabrerizo
- 核验摘录：HBX 表示选择自建多模态 Agent 基础设施，避免锁定单一模型；所有员工参加 AI Foundations，并设置 AI champions。风险控制从 champion/challenger 并行，过渡到 AI 执行、人工检查，最后进入带数字护栏和 Agent 相互监督的全 Agent 阶段。受访者称企业竞争优势将更多来自专有数据和伙伴数据。
- 来源性质：公司高管直接陈述，未获第二独立来源交叉验证。
