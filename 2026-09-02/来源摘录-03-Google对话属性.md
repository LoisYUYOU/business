# 来源摘录｜Google Merchant Center conversational attributes

## 合规事实摘要

- conversational attributes 是可选的补充商品数据，用于帮助 AI 系统和会话 Agent 理解商品细节。
- 官方列出的字段包括问答、文档链接、关联商品、商品组标题、变体选项和热度排名。
- 商家可通过补充数据源或 Merchant API 提交；这些字段不会改变现有商品的审批状态。
- 该页面是通用商品规范，不能据此推断所有旅行商品已完整接入。
