# 合法来源短摘要｜AIHA 酒店 Agent 协议与编排控制层

- 来源：[Agentic Protocols Adapted for Hospitality](https://aihospitalityalliance.com/workgroups/agentic-protocols)、[AI Orchestration Framework for Hospitality](https://aihospitalityalliance.com/workgroups/ai-orchestration)、[标准索引](https://aihospitalityalliance.com/standards)
- 正文日期：2026-10-05、2026-10-08

## 事实摘要（改写）

AIHA 将酒店 Agent 集成拆成发现、身份与权限、业务词汇、协议、控制、状态和证据七层，要求用实际业务记录证明交易，而不是把提及、链接或引荐算作预订。配套编排框架建议在多 Agent 与酒店系统间设置共享控制层，让模型提出动作、确定性代码验证并执行，同时保留权限、幂等、回滚、人工接管和审计证据。

## 使用边界

材料是行业组织发布的开放实施指南，不是监管标准、认证或生产成效。框架未提供数值 ROI，并明确需要在具体酒店技术栈中验证。
