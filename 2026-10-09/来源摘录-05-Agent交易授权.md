# 合法来源摘录｜旅行 Agent 的身份、授权、支付与售后

- 来源：[PhocusWire / PayPal 赞助内容](https://www.phocuswire.com/partner-content/technology/trust-identity-payments-preparing-agentic-commerce-travel)、[PayPal 官方合作公告](https://newsroom.paypal-corp.com/2025-02-12-Sabre-PayPal-and-Mindtrip-Partner-To-Deliver-the-Industrys-First-End-to-End-Agentic-AI-Experience-for-Travel)
- 正文日期：2026-10-08；合作公告 2026-02-12
- 核对重点：Mindtrip、Sabre、PayPal 的责任分工，以及 Agent 交易所需的权限与售后组件。

## 事实摘要（改写）

Mindtrip 负责对话和行程组装，Sabre 提供旅行内容、实时价格、库存、预订与服务能力，PayPal 提供身份验证和支付，消费者在购买前审阅并批准。面向 Agent 的交易系统还需提供客户认证、委托规则、支付权限、商品与结账数据、风控合规、退款、修改和追加支付，并识别 Agent 代表谁、获准做什么及权限何时失效。
